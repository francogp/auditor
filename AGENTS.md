# Purpose

Core standalone static analysis and architecture verification engine (`@francogp/auditor`). Provides the BaseAuditor framework, streaming runner, UnifiedTheme Box-Drawing reporting, CLI tools, AST context caching, and built-in generic suites across all architectural families (including `validate_documented_commands` for authentic documentation commands, `validate_html_validate` for strict HTML5 standards, `validate_stylelint` for stylesheet hygiene, `validate_eslint_config` for domain type compliance, `validate_similar_code` for vector semantic duplication, and `validate_test_coverage` for test execution code coverage).
