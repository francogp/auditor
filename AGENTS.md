# Purpose

Core standalone static analysis, architecture verification, and deterministic code refactoring engine (`@francogp/auditor`). Provides the BaseAuditor framework, streaming runner, UnifiedTheme Box-Drawing reporting, CLI tools (including `auditor-dupes` for clone refactoring and `auditor-magic` for design tokens and magic numbers), AST context caching, and built-in generic suites across all architectural families (including `validate_documented_commands` for authentic documentation commands, `validate_script_commands` for executable scripts and CI/CD pipelines, `validate_html_validate` for strict HTML5 standards, `validate_stylelint` for stylesheet hygiene, `validate_vite_plus_config` for unified Vite+ standards and domain type compliance, `validate_oxlint` for fast syntax and lint hygiene, `validate_oxfmt` for source code formatting hygiene, `validate_similar_code` for vector semantic duplication, and `validate_test_coverage` for test execution code coverage).
